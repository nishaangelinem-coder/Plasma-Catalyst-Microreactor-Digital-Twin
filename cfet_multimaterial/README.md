# CFET multi-material compact-model and circuit-validation flow

Companion repository for the IEEE TED manuscript *"A Unified Physics-Based Compact Model and
Calibrated Circuit-Validation Flow for Multi-Material CFET Logic: Si, SiGe, MoS₂/WSe₂, CNT and GaN"*
(`paper/`).

```
cfet_multimaterial/
├── veriloga/          9 Verilog-A compact models (Spectre/ADE)           <- generated by sim/gen_veriloga.py
├── netlists/ngspice/  ucm_cfet.lib: same equations as ngspice sub-circuits <- generated by sim/ngspice_lib.py
├── netlists/spectre/  Spectre testbenches (device, inverter, RO) + calibrated parameter include
├── cadence/           SKILL (library/cell/symbol/schematic creation), OCEAN (all analyses), ADE setup, MC statistics
├── sim/               Python: model (ucm.py), parameters (platforms.py), reference data, calibration,
│                      ngspice flow (spice.py), nominal/sweep/sensitivity/Monte-Carlo drivers, figures
├── data/              reference I-V curves and calibrated_params.json
├── results/           CSV results, RO waveforms
├── layout/            gdstk GDSII generator, layer map, design rules, DRC/area reports, PNG renders
├── schematics/        schemdraw schematics (SVG/PNG)
├── figures/           all manuscript figures
├── doc/               model specification, calibration targets, Cadence flow walkthrough
└── paper/             IEEEtran LaTeX source, refs.bib, PDF
```

## Reproduce (open-source path, ~2–3 h on 4 cores)

```bash
pip install numpy scipy matplotlib gdstk schemdraw ; apt-get install ngspice
python3 -m sim.make_reference_data      # literature-anchored reference curves
python3 -m sim.calibrate                # Step 13: fit + MAPE -> data/calibrated_params.json
python3 -m sim.gen_veriloga ; python3 -m sim.ngspice_lib ; python3 -m sim.export_cadence_params
python3 -m sim.fig_calibration
bash sim/pipeline.sh                    # nominal, VDD/temperature sweeps, sensitivity, Monte Carlo
python3 -m sim.fig_nominal ; python3 -m sim.fig_sweeps ; python3 -m sim.fig_sensitivity ; python3 -m sim.fig_mc
python3 layout/make_layout.py ; python3 schematics/make_schematics.py
cd paper && pdflatex main && bibtex main && pdflatex main && pdflatex main
```

## Cadence path
See `doc/cadence_flow.md` (maps the 38-step brief to `cadence/skill/*.il`, `cadence/ocean/*.ocn`,
`cadence/ade/*`). The Verilog-A modules in `veriloga/` are the primary deliverable for Virtuoso;
the ngspice library is the open-source stand-in used to generate the results in the manuscript.
